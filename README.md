# Web CC

Sitio web para derribar mitos, con enfoque académico, didáctico y pedagógico.

## Stack

- HTML / CSS / JS sin build tool (sitio estático plano, como la referencia visual).
- [GSAP](https://gsap.com/) + ScrollTrigger para animaciones scroll-driven ("scrollytelling").
- Deploy en Netlify (`netlify.toml` apunta al root del repo).

## Referencia visual

https://natalidad-chile.netlify.app/

## Desarrollo local

Abrir `index.html` directamente en el navegador, o servir la carpeta con cualquier servidor estático
(ej. `npx serve .`).
